## [0.0.1] - 2026-11-09

### Added

- "Image Selector" ACF field type.
- Choices builder in the field group editor: add images from the media library, set each one's name and value, drag to reorder.
- Thumbnail and circle display styles.
- Return value as the value, the name, or an array of both.
- Optional "None" choice.
- Support for conditional logic and ACF's JS field API.
- Admin notice when ACF 6.0+ isn't active.
- Translation support (`fk-acf-image-selector` text domain).
